# Draft angles

Several drafts of one section. The value is in the difference between them, so the first thing to get right is that they are actually different.

## The angles

| Angle | What it changes |
|---|---|
| **Restraint** | Less is said. The character understates. |
| **Pressure** | The scene is harder than it looks. Something is being withheld. |
| **Warmth** | The character is easier to read than expected. |
| **Coldness** | The character is harder to reach than expected. |
| **Specificity** | One concrete, checkable detail instead of an impression. |
| **Ambiguity** | Two readings are live and the text supports both. |
| **Escalation** | The scene ends closer to a break than it began. |
| **Offbeat** | The obvious move is not the move. |

Pick the number of angles that matches the number of drafts requested. Do not reuse an angle.

## The difference test

Two drafts are different only if they would produce **different readings**, not different word choices.

- Different: one draft is warm and the other is cold. The reader gets a different character.
- Not different: one draft says "she laughed softly" and the other says "she let out a quiet laugh".

Test: if you could merge the two drafts into one paragraph without losing anything, they were the same draft.

## Rules

- Every draft obeys the same constraints: the concept, the voice, the budget, the macro rules, the rubric. A draft that breaks a rule is not a variant.
- Each draft is a complete piece of the section, not a sketch of one.
- Present them side by side with a one-line note on the angle each took.

## After the user picks

Develop the chosen draft. Do not merge the others into it, and do not average them.
