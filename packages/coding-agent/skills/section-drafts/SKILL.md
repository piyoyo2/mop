# Section drafts

One section, several genuinely different drafts. The value is in the difference.

## When this applies

- The user asks for options, alternatives, or several versions of a section.
- A single draft is not landing and the user wants to choose a direction.

## Workflow

1. Identify the exact section and any constraint already in force — the character, the voice, the budget, the macro rules.
2. MUST read [draft-angles.md](references/draft-angles.md) before drafting.
3. Produce the requested number of drafts. Each one takes a different angle, not a different wording of the same angle.
4. Present them side by side with a one-line description of the angle each took.
5. The user picks; you then develop the chosen one. You NEVER merge them into an average.

## Reference files

- [draft-angles.md](references/draft-angles.md) — the angles a draft can take, and the test for whether two drafts are actually different.

## Notes

- Two drafts that differ only in adjectives are one draft. Different angle, different content.
- Each draft still has to pass the checks. A variant that breaks a macro rule is not a variant.
