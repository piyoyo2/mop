# Voice profile format

A voice profile captures how a creator writes so that new content can match the pattern without copying their phrasing.

A profile is a Markdown document with these headings, in this order.

```markdown
# Voice profile: <creator, card name, or "unnamed">

## Formatting conventions

## Macros and pronouns

## Prose register

## Notes
```

## The three axes

### Formatting conventions

How this creator lays out each box — the shape of their Scenario, how their Personality box is structured (prose paragraph, trait list, mixed), how their Opening Messages open, how their Example Dialogue is staged.

Record the shape, not an example of it.

### Macros and pronouns

Which macros they use and how densely, whether they address the user by name or by role, what pronoun set their prose uses, how they refer to themselves in third person.

### Prose register

Sentence rhythm and length, vocabulary level, how much dialogue against description, whether the prose is clipped or lyrical, what they never do.

## Notes

Anything that does not fit the three axes but is stable across the samples: recurring motifs, a habit of ending a beat on a question, a consistent avoidance.

## Rules

- **Three axes only.** Quality is not an axis. Never assess how good the creator is.
- **Never quote a sample at length.** A short phrase is fine to name a pattern. A paragraph is a copy.
- **Describe, do not transcribe.** "Short declaratives, present tense, ends on an action" — not "the door was red and she did not look at it".
- **Never state who the creator is** beyond what the samples show.

## Using a profile

Read the profile, then write. You are matching the pattern, not reproducing a passage. If the output would contain a recognizable sentence from a sample, it is wrong.

The profile constrains register and structure. It does not supply content, and it does not override the card's own concept.
