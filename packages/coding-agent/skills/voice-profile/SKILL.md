# Voice profile

A profile captures how a creator writes, so new content can match the pattern without copying their phrasing.

## When this applies

- The user asks you to write "like" a named creator, or in a style they have samples of.
- The user wants to build a voice profile from sample cards.
- A saved voice profile exists and the user wants it applied.

## Workflow

1. When building a profile: MUST read [voice-profile-format.md](references/voice-profile-format.md) before writing. The section order is fixed.
2. Extract three axes only: box-formatting conventions, macro and pronoun habits, prose register. NEVER assess quality.
3. NEVER quote a sample at length. Capture the pattern, not the text.
4. When applying a profile: read the profile, then write. You are matching the pattern, never reproducing a passage.
5. NEVER copy phrasing from the samples. If the output would contain a recognizable sentence from a sample, it is wrong.

## Reference files

- [voice-profile-format.md](references/voice-profile-format.md) — the exact document structure, the three axes, and the extraction rules.

## Notes

- Profiles are saved in the library. Use the `lore-library` skill to save one.
- A profile describes a register, not a person. It never states who the creator is or how good they are.
