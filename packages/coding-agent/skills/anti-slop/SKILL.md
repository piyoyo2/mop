# Anti-slop

The bar a card has to clear. Applies to prose, not to schema: a card can be perfectly valid and still not worth shipping.

## When this applies

- You are reviewing a draft against quality rather than structure.
- The user says a card reads generic, bloated, or "AI-written".
- You are rewriting to remove tells, clichés, or padding.

## Workflow

1. MUST read [rubric.md](references/rubric.md) before judging a draft.
2. Read the draft against each rubric dimension in turn. Report concrete problems with a location; never a verdict without one.
3. MUST read [banned-phrases.md](references/banned-phrases.md) when the specific tells are in question.
4. Fix the highest-impact problems first. A cut that removes a cliché but leaves three others is not a fix.
5. Re-read the result against the rubric. NEVER declare a draft clean on the strength of the edit you just made.

## Reference files

- [rubric.md](references/rubric.md) — the anatomy of a bad card: genericness, unearned scenes, unedited text, structural failures.
- [banned-phrases.md](references/banned-phrases.md) — the descriptor, reaction, staging, and hedging patterns that mark generated prose.

## Notes

- The rubric scores the card, not the author. NEVER tell a user their writing is bad; report what fails and let them decide.
- A banned phrase is a signal, not a verdict. One instance of "breath caught" is a tell; a character who breathes caught is not.
