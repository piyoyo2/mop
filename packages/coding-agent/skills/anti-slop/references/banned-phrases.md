# Banned phrases and patterns

These are the patterns that mark generated prose. A single instance is a tell. A character who genuinely gazes is not a problem — the pattern is.

## Descriptors

```
gaze · orbs · smirk · chiseled · lithe · porcelain · sculpted · ethereal · striking
```

## Reaction verbs

```
breath caught · heart stuttered · heat pooled · pulse quickened
stomach dropped · knees weakened
```

## Narration props

Props inserted to carry the scene when the writing has no other way to move it — the slow blink, the deliberate pause, the fingers that stop mid-reach.

## Intimacy staging

```
pulled them closer · their eyes met · the air between them
electricity · tension crackled
```

## Purple prose

```
a symphony of · a testament to · a dance of
```

## Hedging

```
perhaps · seemed to · somewhat · almost as if
```

## Sensory clichés

```
sends shivers down your spine · barely above a whisper · a mischievous glint
```

## Formulaic contrast

A sentence of the shape "it's not just X, it's Y" or "it's not X, it's Y". The pattern, not the words, is the tell — a single contrast is fine; a paragraph built on them is not.

## How to use this list

It is a screening tool, not a ban. Do not mechanically delete every hit: the fix for "a mischievous glint" is usually to write what the face is actually doing, not to substitute a different adjective. A card that swaps one cliché for another has not improved.
