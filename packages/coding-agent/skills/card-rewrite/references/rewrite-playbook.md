# Rewrite playbook

## Diagnose before you write

A rewrite that does not name the failure will not fix it. Each failure has a distinct fix:

| Failure | The fix |
|---|---|
| Generic character | Replace traits with specific, checkable particulars. Not "determined" but the specific thing she is determined about. |
| AI tells | Cut the pattern, then write what the moment actually contains. Do not swap one cliché for another. |
| Padding | Delete, then see what breaks. If nothing breaks, it was padding. |
| Bloat | Offload into a lorebook. Do not cut content the character needs. |
| Structural failure | Rewrite the box, not the sentences. A frozen Scenario cannot be fixed by rewording. |
| Voice drift | Fix the register, not the words. Read the profile and re-derive the rhythm. |
| Contradiction | Pick which side is right and change the other. |

## The iteration loop

For a requested number of rounds:

1. Draft.
2. Review it — the `review` skill.
3. Fix the findings, highest impact first.
4. Re-check: macros (`card_macro_check`), budget (`card_budget`), structure.
5. Repeat until the round count is reached.

Report what each round changed. A round that changed nothing is worth reporting as a round that changed nothing.

Stop at the round count the user asked for. Do not run extra rounds because the draft "almost passed".

## Over budget

Never cut to fit a band without reporting it.

1. Identify what in the permanent boxes is only sometimes needed.
2. Propose a lorebook entry for it, with the keyword that would trigger it.
3. Get the user's decision: offload, or cut.
4. Cut only what the user chose to cut, and report exactly what was removed.

## Slop mode

A fast, disposable draft: skip the quality rubric and the auto-review, keep the schema. Four boxes, working macros, valid lorebook JSON — and no claim that it is good. Say clearly that it is a draft.

Slop mode is for getting a shape on the screen. It is never for shipping.
